## Introduction

The Stair-Doc backend uses [FastAPI](https://fastapi.tiangolo.com/) — a modern, high-performance Python web framework with automatic OpenAPI documentation, Pydantic v2 validation, and async support.

Run the **API only** from the `apps/api` directory:

```bash
pnpm run dev
# or directly
python run.py
```

### Src directory

| Item             | Description                                           |
| ---------------- | ----------------------------------------------------- |
| `api`            | API routers and endpoint handlers                     |
| `core/socket.py` | Socket.IO server + background telemetry broadcaster   |
| `crud`           | Reusable CRUD base class + model-specific operations  |
| `models`         | SQLAlchemy / Supabase table models                    |
| `schemas`        | Pydantic v2 request/response schemas                  |
| `config.py`      | Settings (loaded from `.env` via `pydantic-settings`) |
| `main.py`        | FastAPI app factory, middleware, lifespan             |

### Root directory

| Item               | Description                                           |
| ------------------ | ----------------------------------------------------- |
| `package.json`     | Enables `pnpm run dev` from the monorepo root         |
| `run.py`           | Entry point: `uvicorn` launcher used in production    |
| `pyproject.toml`   | Poetry configuration and Python version pin           |
| `requirements.txt` | Pip-compatible dependency list for Railway deployment |

## Dependencies

### Python 3.10+

The project targets **Python 3.10+** (deployed on Railway which supports any modern Python version). Key dependencies:

| Package             | Purpose                                  |
| ------------------- | ---------------------------------------- |
| `fastapi`           | Web framework                            |
| `uvicorn`           | ASGI server                              |
| `pydantic-settings` | Typed settings from `.env`               |
| `python-socketio`   | Socket.IO server for real-time telemetry |
| `supabase-py-async` | Async Supabase client                    |
| `PyJWT` + `passlib` | JWT authentication and password hashing  |
| `pywebpush`         | VAPID-based web push notifications       |

### Supabase

The project uses [Supabase](https://supabase.com/) as the PostgreSQL backend. `supabase-py-async` is listed in `pyproject.toml`. If you switch to a different database, remove that dependency and update `src/api/deps.py`.

## Adding your own endpoints

The project follows a three-layer pattern: **Schema → CRUD → Endpoint**.

### Example: Adding a new delivery status endpoint

#### Step 1: Add or extend a schema

```python src/schemas/delivery.py
from pydantic import BaseModel
from enum import Enum

class DeliveryStatus(str, Enum):
    PENDING = "pending"
    IN_TRANSIT = "in_transit"
    DELIVERED = "delivered"
    FAILED = "failed"

class DeliveryStatusResponse(BaseModel):
    id: str
    status: DeliveryStatus
    updated_at: str
```

#### Step 2: Add CRUD (if needed)

For simple read operations, extend `CRUDBase` in `src/crud/base.py`. For complex queries, add a method directly to the relevant CRUD class (e.g., `CRUDDelivery` in `crud_delivery.py`).

#### Step 3: Add the endpoint handler

```python src/api/api_v1/endpoints/deliveries.py
@router.get(
    "/{delivery_id}/status",
    response_model=ApiResponse[DeliveryStatusResponse],
    status_code=200,
)
async def get_delivery_status(
    delivery_id: str,
    session: SessionDep,
) -> ApiResponse[DeliveryStatusResponse]:
    """Get the current status of a specific delivery."""
    delivery = await crud_delivery.get(session, id=delivery_id)
    if not delivery:
        raise HTTPException(status_code=404, detail="Delivery not found")
    return success_response(
        data=DeliveryStatusResponse.model_validate(delivery),
        message="Delivery status retrieved"
    )
```

#### Step 4: Register in `api.py` (if adding a new router)

```python src/api/api_v1/api.py
from src.api.api_v1.endpoints import my_new_module
api_router.include_router(my_new_module.router)
```

#### Step 5: Update Supabase

Ensure the corresponding table exists in your Supabase project with columns matching your Pydantic schema. See the [Local Development](../local-development) guide for the required tables.
