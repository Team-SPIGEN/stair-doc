## What is Stair-Doc?

**Stair-Doc** is an autonomous stair-climbing delivery robot application for office file and container delivery between floors. The robot uses 2D LIDAR SLAM for mapping and navigation, can climb stairs using a tracked chassis with servo arms, and secures deliveries with RFID-locked containers.

This documentation covers the full-stack monorepo: a **Next.js 15 PWA** for the control dashboard, a **FastAPI** backend for robot telemetry and business logic, and this **Mintlify** documentation site — all orchestrated by **Turborepo**.

## Key Features

**Robot Control Dashboard (PWA)**\
The Next.js application is a mobile-first Progressive Web App that includes:

- Real-time robot telemetry via Socket.IO (battery, location, speed)
- 2D LIDAR map visualisation and navigation controls
- Delivery queue management (create, assign, track, archive)
- RFID container lock/unlock monitoring
- Live camera feed for recipient identity verification
- Emergency stop with full-screen overlay and haptic feedback
- Push notifications, offline queue, and installable PWA

**Robot API (FastAPI)**\
The FastAPI backend includes:

- JWT authentication with role-based access (operator / recipient / admin)
- REST endpoints for robots, deliveries, RFID tags, camera, and analytics
- Socket.IO rooms for real-time telemetry broadcast
- Push notification subscription management (Web Push / VAPID)
- Voice command processing

**Documentation**\
Built using Mintlify, a fully responsive documentation site featuring:

- Getting-started guides and local development setup
- Configuration references for every component
- Interactive API playground from the FastAPI OpenAPI schema

## User Roles

| Role          | Description                                                                 |
| ------------- | --------------------------------------------------------------------------- |
| **Operator**  | Manages the delivery queue, controls the robot manually, monitors telemetry |
| **Recipient** | Receives deliveries, unlocks RFID containers, confirms delivery via camera  |
| **Admin**     | Manages users, RFID tags, robot configuration, and views analytics          |

## Core Delivery Workflow

```
1. Operator creates a delivery → assigns RFID tag → dispatches robot
2. Robot navigates autonomously (LIDAR SLAM → stair climbing → arrival)
3. Recipient taps RFID card → container unlocks → confirms via camera
4. Robot returns to base → operator archives delivery
```
